# Device Tree for Redmi Note 10S / POCO M5s (rosemary)

The Redmi Note 10S (codenamed "rosemary") is a mid-range smartphone from Xiaomi. It was announced in March 2021 and released in April 2021.

The POCO M5s (codenamed "rosemary") shares the same hardware as the Redmi Note 10S. It was announced and released in September 2022.

## Device specifications

| :---------------------- | :-----------------------------------------------------------------------------|
| Chipset                 | MediaTek MT6785V Helio G95 (12 nm)                                            |
| CPU                     | Octa-core (2x2.05 GHz Cortex-A76 & 6x2.0 GHz Cortex-A55)                    |
| GPU                     | Mali-G76 MC4                                                                  |
| Memory                  | 4/6/8 GB LPDDR4X                                                              |
| Shipped Android Version | 11.0 (MIUI 12.5)                                                              |

| SIM                     | Dual SIM (Nano-SIM, dual stand-by)                                            |
